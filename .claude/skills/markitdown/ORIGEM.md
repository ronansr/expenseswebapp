# De onde veio esta skill

**O `SKILL.md` desta pasta foi escrito por nós**, em 24/08/2026. Nao ha skill oficial: o
`github.com/microsoft/markitdown` (MIT, commit `9dc0d65`) publica uma biblioteca
Python, um CLI e um servidor MCP — nenhum `SKILL.md`.

O que a skill carrega e o **uso**: quando converter, como instalar sem sujar o Python do
sistema, e os tres modos de errar que custam caro (PDF escaneado saindo vazio, tabela
mesclada saindo torta, e despejar o markdown inteiro no terminal).

Ao atualizar, o que se compara e o `README.md` do repositorio de origem — a lista de
extras opcionais e as flags do CLI sao o que envelhece.

**Alternativa ao CLI:** o pacote `markitdown-mcp` expoe a mesma conversao como
servidor MCP, se um dia for melhor te-la como ferramenta do que como comando.
